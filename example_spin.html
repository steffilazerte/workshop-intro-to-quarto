Render report

Quarto can render R scripts directly.

This is the code you can use to render this report. This will automatically rename it with today’s date. Note the eval: false which makes sure that rendering this report doesn’t run the code to render the report (infinite loop!)

quarto::quarto_render(
  input = "example_spin.R",
  output_file = paste0("example_spin_", Sys.Date(), ".html")
)
